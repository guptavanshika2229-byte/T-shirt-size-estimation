# AI-Based T-Shirt Size Estimation

An AI and Computer Vision based system for estimating body measurements and recommending a suitable T-shirt size.

## Project Objective

The system will estimate a person's body measurements and T-shirt size using:

- Front image
- Side image
- Height
- Optional gender
- Optional weight
- Live webcam/video input

## Planned Features

- Front image based body analysis
- Side image based body analysis
- Human pose detection
- Body landmark extraction
- Body measurement estimation
- T-shirt size prediction
- Real-time webcam prediction
- Measurement visualization on screen
- Written measurement and size output
- Streamlit web application
